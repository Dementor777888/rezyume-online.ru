Целевой уровень: WCAG 2.1 AA.

## Проблема P1: зелёный текст
`--brand-green` #7CB342 на белом = **2.6:1 — AA fail**. Сейчас так окрашены текст-ссылки («Смотреть шаблон →», «Взять за основу →», inline-ссылки статей, «Открыть FAQ →», активные пункты NAV).
**Правило для разработки:** любой зелёный ТЕКСТ мельче 24px — только `--brand-green-dark` #3F6B22. `#7CB342` — заливки, иконки ≥20px с текстовым дублем, бордеры, прогресс-бары.

## Прочие правила
- **Фокус:** видимый focus-visible ring (2px `--brand-green`, offset 2px) на всех интерактивах; не убирать outline без замены.
- **Белый на raw `--brand-green`** (#7CB342) = 2.9:1 — допустим только для крупного жирного текста (заголовки зелёных панелей ≥19px bold); мелкие подписи на зелёных панелях делать `rgba(255,255,255,.92)` и ≥14px — или фон `--brand-green-dark`.
- **Формы:** каждый input — с `<label for>`; ошибки — текстом + цветом (не только цветом), `aria-describedby`; согласия — настоящие `<input type=checkbox>`, НЕ предотмеченные.
- **Аккордеоны (FAQ):** `<button aria-expanded>` + регион с `aria-controls`.
- **Модалки** (подписка Базы, превью конструктора): focus-trap, `Esc`, `aria-modal`, возврат фокуса.
- **Таблицы админки:** `<th scope="col">`; иконки-действия — с `aria-label` («Редактировать», «Удалить») и `title`.
- **Изображения:** hero-portrait — содержательный alt («Пример фото кандидата»); декоративные паттерны обложек — `alt=""`; foliage-волна — `aria-hidden`.
- **Иконки-only кнопки** (гамбургер, ✕ тостов) — `aria-label`.
- **Прогресс конструктора:** «Шаг N из 6» дублируется текстом ✔ — сохранить; бар с `role=progressbar`.
- **Тач-цели:** ≥44×44 на мобайле (админ-таблицы — минимум 40).
- **Motion:** переходы ≤200ms, ничего не мигает; `prefers-reduced-motion` — отключить подсветку-транзишены превью.
- **Язык:** `<html lang="ru">` на всех страницах.

## Минимальные размеры текста
UI-минимум 12px (сейчас есть 11–11.5px в бейджах — поднять при верстке). Печатные шаблоны резюме — самостоятельный контекст (PDF), там допустимы 10.5–11px в метаданных.
