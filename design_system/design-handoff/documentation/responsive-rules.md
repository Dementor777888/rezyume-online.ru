# Responsive Rules — «Резюме Онлайн»

Макеты существуют в двух точках: **desktop** (канвас 1320, контент max-width 1180) и **mobile** (390). Всё между ними — по правилам ниже. Рекомендуемые брейкпоинты: `<768` mobile, `768–1023` tablet, `≥1024` desktop.

## Глобально
- Контент центрируется, `max-width: 1180px`, поля 40px (desktop) / 16px (mobile).
- Страничный фон `--bg-tint`, карточки белые.
- Шрифтовая шкала: hero 44→30, H1 30→24, H2 24→20; body не уменьшается ниже 14px.
- Touch-цели на мобайле ≥44px (иконки-действия таблиц — минимум 40px).

## Header
- Desktop: логотип + 6 пунктов NAV + «Вход» + жёлтый CTA.
- Mobile: логотип + гамбургер. **Drawer не спроектирован** — до верстки: полноэкранный список NAV + Вход + CTA (см. design-audit P2).

## Сетки каталогов (Образцы, Шаблоны, База, Статьи)
- Desktop: `grid-template-columns: repeat(auto-fill, minmax(210–280px, 1fr))` — самоадаптация закрывает планшет.
- Mobile: Образцы/База — 2 колонки (`1fr 1fr`); Шаблоны/Статьи — 1 колонка.
- Сайдбар каталога: desktop — левая колонка 240–260px; mobile — схлопывается наверх (полосой, макс-высота 240–260 со скроллом).

## Детальные страницы (Образец, Шаблон, Резюме из Базы)
- Desktop: `1fr + 300–330px` sticky-колонка справа (top: 28).
- Mobile: одна колонка, порядок: превью → инфо-карточка → похожие.
- Превью резюме: масштаб 0.72 desktop / 0.52 mobile через ResumeScaler (sized wrapper! см. component-spec).

## Конструктор
- Desktop: форма + sticky-превью справа (ширина превью 620×0.5).
- Mobile: превью скрыто; fixed нижняя панель «Предпросмотр | Далее» (padding-bottom у контента); превью — по кнопке в модалке.
- Поля: 2 колонки → 1 колонка.

## Превью + экспорт
- Desktop: чипы-фичи вертикальной колонкой слева от превью; офферы справа `1.15fr/0.85fr`.
- Mobile: чипы горизонтальной полосой над превью (flex row, равные ширины), офферы одной колонкой ниже.

## Оплата, Вход
- Центрированная карточка ≤560px; на мобайле — full-width с полями 16px.

## FAQ
- Desktop: категории слева 220px (sticky, column, без wrap) + карточка вопросов.
- Mobile: категории — горизонтальные чипы с переносом, затем карточка.

## Поддержка
- Desktop: форма + правая колонка 330px (Telegram, время ответа, FAQ).
- Mobile: форма, затем боковые карточки одной колонкой.

## Кабинет админа
- Desktop: сайдбар 240px + рабочая область; контейнер 1240px.
- Mobile: сайдбар наверх; таблицы: сокращённые заголовки («Код», «Осталось», «До»), паддинги ячеек 8px, min-width снят. Таблицы контент-разделов (5+ колонок) сохраняют горизонтальный скролл — осознанно, админка mobile — second-class.

## Футер
- 4 колонки → аккордеон/стек одной колонкой; foliage-волна сохраняется на всех ширинах (SVG, `preserveAspectRatio`).

## Что проверить вручную при верстке (нет макетов)
1. 768–1024: сетки каталогов (2–3 карточки в ряд), шапка ещё desktop-вариант или уже drawer (рекомендация: drawer <900px).
2. Конструктор на 768: превью справа уже не влезает — скрывать превью <1024.
3. Длинные слова в заголовках карточек («Административный персонал») — `hyphens: auto` для ru.
