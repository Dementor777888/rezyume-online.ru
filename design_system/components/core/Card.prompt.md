Generic surface container — soft rounded corners, airy shadow, thin hairline border. Used under review cards, template gallery cards, feature blocks.

```jsx
<Card>
  <h3>Быстрый результат</h3>
  <p>Готовое резюме за 10 минут.</p>
</Card>
```

Set `elevated={false}` for a flat bordered variant (e.g. nested inside another card).
