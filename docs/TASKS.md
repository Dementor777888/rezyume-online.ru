# TASKS.md — пошаговый backlog для Codex

## Как работать с задачами

- Codex получает одну задачу за раз.
- Перед задачей Codex читает `docs/CODEX.md`.
- Если задача меняет API, данные или UI-контракт, обновляется соответствующий Markdown-файл.
- Задачи ниже идут в рекомендуемом порядке.

## P3. Сохранение и бесплатный PDF

### P3.01 — Создать API сохранения анонимного Resume

**Цель:** сохранить результат для PDF и публичной ссылки.

**Сделать:**

- `POST /api/resumes`.
- Создание `Resume` с:
  - `userId = null`;
  - `tier = free`;
  - `status = published`;
  - `expiresAt = now + 24h`;
  - `publicToken`;
  - `editTokenHash`.
- Вернуть `resumeId`, `publicUrl`, `editToken`.

**Готово, если:**

- запись появляется в БД;
- publicToken уникален;
- editToken возвращается только один раз при создании.

### P3.02 — Создать print route

**Цель:** единый HTML для PDF.

**Сделать:**

- `/print/resume/[id]`.
- Рендер выбранного шаблона.
- CSS print A4.
- Только server-side доступ для PDF-генератора.

**Готово, если:**

- route рендерит A4-версию;
- UI-сайт не показывает print route как обычную страницу.

### P3.03 — Реализовать PDF export

**Цель:** скачать PDF бесплатно.

**Сделать:**

- `POST /api/resumes/[id]/export/pdf`.
- Playwright Chromium.
- Кэш в `storage/pdf`.
- Инвалидация при изменении резюме.
- Корректные шрифты с кириллицей.

**Готово, если:**

- PDF открывается;
- кириллица корректная;
- поля не обрезаются;
- повторный экспорт использует кэш.

### P3.04 — Реализовать публичную ссылку

**Цель:** дать пользователю share-link.

**Сделать:**

- `/rezume/[publicToken]`.
- Для free показать плашку «Ссылка активна 24 часа».
- Если free-ссылка истекла, показать страницу истечения.
- Для paid не показывать срок.

**Готово, если:**

- ссылка открывается без авторизации;
- expired free не раскрывает резюме;
- контакты публичной ссылки показываются только в обычной share-link, не в Базе резюме.
