# PRD — Резюме онлайн

> Продуктовые требования. Опирается на `competitor-research.md` и `about_business.md`. Живёт в одном месте, дублирования с другими доками нет: архитектура — в `ARCHITECTURE.md`, данные — в `data-model.md`, дизайн — в `design-brief.md` (позже — `design-system.md` по итогам Claude Design).

---

## 1. Что строим

Онлайн-сервис создания красивого резюме. Пользователь заполняет квиз-форму, выбирает шаблон и получает оформленный PDF. Бесплатно — резюме уровня платных конкурентов (2 шаблона, PDF, ссылка на 24 ч, без регистрации). За 99 ₽ разово — AI-слой: улучшение фото, все шаблоны, DOCX, бессрочная ссылка и личный кабинет; на следующих шагах — голосовой ввод, парсинг старого резюме и функции прохождения AI-отсева работодателей.

**Одной строкой:** то, что конкуренты продают, у нас бесплатно; за 99 ₽ один раз — AI-резюме, которое проходит отсев работодателей. Без подписки, которой все боятся.

## 2. Для кого

Люди в поиске работы, которым нужен профессионально оформленный результат без дизайнера и без Word. Без опыта в вёрстке. Ценят скорость и результат, а не процесс. Три сегмента: безработные в активном поиске, работающие в поиске лучшего места, ищущие подработку. Только русскоязычные. Обращение в интерфейсе — на «Вы».

## 3. Принципы продукта

1. **Честность оплаты.** Разовый платёж, никаких скрытых подписок и привязки карты для рекуррента. Цена и модель — на входе, не в конце. Это ядро позиционирования против рынка (см. `competitor-research.md`, разд. 4).
2. **Скорость.** Голос + автоподсказки + загрузка файла. Цель — 5 минут против 30–60 вручную.
3. **Простота.** Всё ведёт к результату прямо. Без обязательной регистрации до результата. Без перегруженного дизайна.
4. **AI под капотом.** Разбор данных, улучшение фото, формулировки — незаметно для пользователя.

## 4. Ключевые ограничения (для инженерии)

- **Очереди не нужны.** Одновременных генераций мало, любой обычный хостинг выдержит. Не закладывать очереди/воркеры/оркестрацию — это переусложнение.
- Приоритет простых решений без избыточной архитектуры. Стек выбирается под задачи.
- Кириллица в PDF/DOCX — обязательная техническая задача Шага 1, не «потом».
- Из SaaS переиспользуется: оплата, промокоды, лимиты. НЕ переиспользуется: очереди. Детали — в `reuse-map.md`.

## 5. Скоуп по фазам

### Шаг 1 — MVP (запуск)

**Входит:**

*Бесплатный контур (без личного кабинета):*
- Конструктор-визард, 6 шагов: Контакты → Опыт → Образование → Навыки → Фото → Шаблон. Sticky live-превью справа (мобайл — нижняя модалка). Подсказки soft/hard skills, секции с «+/−».
- На последнем шаге — обязательный чекбокс согласия на обработку ПД (блокирует продолжение) + опциональный чекбокс публикации в Базе резюме.
- 2 шаблона «Старт»/«Старт+фото»: светло-голубой сайдбар (`--brand-blue-tint #E4F1F9`) + жёлтые акценты. Фото пользователь вставляет сам, без улучшения. Нет фото → «Старт», есть → «Старт+фото».
- Скачивание PDF бесплатно. Онлайн-ссылка — 24 часа.
- Черновик в браузере (localStorage) + восстановление по ссылке. Без регистрации.

*Платный контур — «AI-версия» (99 ₽ разово); в MVP из пакета реализуются:*
- Все 5 платных пресетов («Чистый» — дефолт, «Компакт», «Одна колонка», «Академический», «Акцент») + переключение акцента (синий/teal/графит); референсы — DOCX 1–15 и `design_system/ui_kits/resume-templates/`.
- AI-улучшение фото (Google Nano Banana).
- PDF + DOCX с рабочей кириллицей.
- Бессрочная ссылка (в нашей базе).
- Личный кабинет: email перед оплатой → ЛК → пароль на почту. Несколько резюме на аккаунт, статусы черновик/опубликовано, правки и скачивания бесплатны.
- Письмо после оплаты: файлы + пароль от ЛК + бессрочная ссылка.

*Контентные и служебные страницы (в MVP, по дизайну — 16 экранов):*
- Примеры резюме — SEO-каталог: разделы → подразделы → профессии (целевой объём 17 разделов · 500+ профессий), перелинковка. Детали — `seo-catalog.md`.
- Статьи (блог), FAQ (schema.org-разметка на лендинге), Поддержка (форма + Telegram-бот), 404.
- Админ-панель: промокоды (генерация + таблица), CRUD контента (Образцы, Шаблоны, База резюме, Статьи, FAQ), служебные страницы, редактируемые title/meta description.

*Общее:*
- Автосохранение по мере ввода.
- Цена и модель — честно, на входе, без подписки.
- Все экраны — десктоп + мобайл (по дизайн-системе).

**Не входит в MVP:** голос, импорт старого резюме, AI-усиление текста, подгонка под вакансию, cover letter, «честный разбор»/ATS (это фичи AI-версии Шагов 2–3), импорт LinkedIn, трекинг откликов, База резюме как публичный каталог (Шаг 3). Кириллица в PDF — обязательна с первого дня.

> **Важно (по итогам дизайна):** продуктово платный пакет один — «AI-версия · 99 ₽». В него входят ВСЕ AI-фичи (голос, импорт, усиление, подгонка под вакансию, письмо, фото). Шаги 2–3 — это порядок РАЗРАБОТКИ фич пакета, не отдельные тарифы. В UI каждая платная фича маркируется чипом «AI · 99 ₽»; до реализации фича в интерфейсе не показывается.

### Шаг 2 — Дифференциация (фичи AI-версии)

- **Голосовая надиктовка + AI-разбор по полям** (killer-фича, аналогов в РФ нет). В конструкторе — на шагах «Контакты» (О себе) и «Образование».
- Загрузка старого резюме/файла → AI-парсинг как второй вход.
- AI-усиление формулировок (STAR: обязанности → достижения с цифрами) — шаг «Опыт».
- Больше шаблонов.

### Шаг 3 — Захват рынка (функции повышения шанса трудоустройства; фичи AI-версии + контент)

Контекст: работодатели сами отсеивают резюме ИИ. Наша цель — чтобы резюме из платного контура гарантированно проходили этот AI-барьер, пока у конкурентов «красивые карточки с непонятным результатом». Это финальное поле конкуренции.

- **«Честный разбор» после генерации** — единый экран: вердикт, сильные стороны, риски, ATS-проходимость в %, правки «Было → Стало», вероятные вопросы на собеседовании с пояснением «почему спросят». Превращает конструктор в карьерного помощника (лучший паттерн рынка, у массовых конкурентов нет).
- ATS-проверка и скоринг с конкретными причинами (не просто %).
- Адаптация под вакансию (вставил текст вакансии → подгонка + ключевые слова).
- Генерация сопроводительного письма.
- SEO-каталог: примеры резюме по профессиям + гайды (генератор органического трафика).
- Каталог резюме пользователей (бесплатных и платных) — только по явному согласию и в деперсонализированном виде. Двойная функция: соцдоказательство + SEO-контент. Правила — раздел 9.

## 6. User stories

**MVP:**
- Как соискатель, я хочу заполнить форму по шагам с подсказками, чтобы не думать, что писать в каждом поле.
- Как соискатель, я хочу бесплатно скачать готовое резюме (уровня платных конкурентов), чтобы получить результат без риска.
- Как соискатель, я хочу увидеть превью до оплаты, чтобы понимать, за что плачу.
- Как платящий, я хочу указать email перед оплатой и получить пароль от личного кабинета на почту, чтобы резюме не потерялось.
- Как платящий, я хочу AI-улучшенное фото, все шаблоны и DOCX за 99 ₽ один раз — и быть уверенным, что больше ничего не спишут.
- Как платящий, я хочу в любой момент зайти в кабинет, исправить резюме и скачать заново — бесплатно.
- Как соискатель, я хочу поделиться ссылкой на резюме с работодателем.
- Как соискатель, я хочу продолжить с того места, где остановился, если закрыл вкладку.

**Шаг 2:**
- Как соискатель, я хочу надиктовать данные голосом, чтобы заполнить резюме за минуты.
- Как соискатель, я хочу загрузить старое резюме и получить его разобранным по полям автоматически.

**Шаг 3:**
- Как соискатель, я хочу проверить резюме на прохождение ATS, чтобы его не отсеял робот.
- Как соискатель, я хочу подогнать резюме под конкретную вакансию.
- Как соискатель, я хочу по желанию опубликовать своё резюме в каталоге (со скрытыми контактами), чтобы меня нашли работодатели — и в любой момент убрать его.

## 7. Метрики успеха

- Конверсия «начал заполнять → получил превью».
- Конверсия «превью → оплата» и «скачал базовый бесплатно → вернулся и оплатил».
- Время заполнения (цель — медиана ≤ 5 мин на Шаге 2 с голосом).
- Доля возвратов/жалоб на оплату (цель — near-zero; это наш дифференциатор).
- Органический трафик из SEO-каталога (Шаг 3).

## 8. Монетизация

**Модель: free = уровень конкурентов бесплатно, paid = AI и трудоустройство.**
То, что конкуренты продают (красивый шаблон, скачивание), мы отдаём бесплатно — это выжигает их поляну и генерит трафик/доверие. Деньги берём за то, чего нет ни у кого: AI-улучшение, скорость ввода, прохождение AI-отсева работодателей.

Платный пакет один — **«AI-версия · 99 ₽»**. Каждая платная фича в UI помечена янтарным чипом «AI · 99 ₽»; фичи появляются в интерфейсе по мере реализации (Шаги 2–3).

| | Бесплатно | AI-версия (99 ₽ разово) |
|---|---|---|
| Заполнение | Руками, с подсказками | + диктовка голосом, + импорт старого резюме (PDF/DOCX) |
| Формулировки | Базовые подсказки | AI-усиление текста (обязанности → достижения с цифрами) |
| Шаблоны | 2: «Старт» / «Старт+фото» (голубой сайдбар + жёлтые акценты) | Все 5 пресетов + переключение акцента |
| Фото | Вставляет сам, без улучшения | AI-улучшение (Nano Banana) |
| Форматы | PDF | PDF + DOCX |
| Ссылка на резюме | 24 часа | Бессрочно |
| Личный кабинет | Нет (черновик в браузере) | Да: несколько резюме, правки и скачивания — бесплатно и без лимита |
| Трудоустройство | — | Подгонка под вакансию, сопроводительное письмо, «Честный разбор» с ATS-% (Шаг 3) |

Правило кнопок (из дизайн-системы): жёлтая = конверсионное/платное действие, зелёная = бесплатное продолжение.

| Параметр | Значение |
|---|---|
| Подписка | Нет. Принципиально. |
| Промокоды | Да (модуль из SaaS): скидка/бесплатный доступ для партнёров и акций |
| Возврат | Без вопросов в течение 7 дней — усиливает позиционирование честности |
| Повторные покупки | Редкие (обновление резюме раз в 1–2 года) |

**Аккаунты и оплата:**
- Бесплатная версия — без личного кабинета вообще. Черновик в браузере (localStorage).
- Перед оплатой запрашиваем email → создаём личный кабинет → высылаем пароль на почту. Оплаченное резюме хранится в ЛК: зайти, исправить, скачать в любой момент; ссылка живёт в нашей базе бессрочно.
- Письмо после оплаты: файлы + пароль от ЛК + бессрочная ссылка.

Каналы трафика — органика: SEO, YouTube, трастовые площадки. Платной рекламы нет. Бюджет старта — $2 000–3 000 на разработку и инфраструктуру.

## 9. Каталог резюме и персональные данные (152-ФЗ)

Каталог показывает резюме реальных пользователей. Резюме содержит ПДн (ФИО, телефон, email, дата рождения, город). Публикация чужих ПДн без правильного согласия — прямое нарушение 152-ФЗ и одновременно повтор паттерна, на который жаловались клиенты конкурентов. Поэтому жёсткие правила:

**По умолчанию каталог выключен.** Ни одно резюме не попадает в каталог само. Публикация — только по явному действию пользователя.

**Два разных согласия (не путать):**
1. Согласие на обработку ПДн — при создании резюме (нужно всегда, для работы сервиса).
2. **Отдельное** согласие на распространение (публикацию) ПДн — только для каталога. По ст. 10.1 152-ФЗ это самостоятельное согласие, его нельзя зашивать в общее «галочкой по умолчанию», формулировка должна прямо называть, какие данные и где публикуются.

**Деперсонализация в каталоге:**
- Прямые контакты (телефон, email) по умолчанию скрыты. Связь — через внутреннюю форму/кнопку «Откликнуться», без раскрытия контактов.
- Точную дату рождения не показывать (максимум — возраст или ничего).
- Дать пользователю выбор, что скрыть перед публикацией (фамилию, город, фото).
- Для SEO-примеров по профессиям использовать полностью обезличенные резюме (вымышленные/агрегированные данные) — тогда это уже не ПДн и согласие на распространение не требуется. Это безопасный основной источник SEO-каталога; каталог реальных людей — отдельная опциональная витрина.

**Права пользователя:**
- Мгновенный отзыв согласия и удаление из каталога в один клик, без переписки с поддержкой.
- Полное удаление ПДн по запросу.

**Инфраструктура и комплаенс:**
- Хранение ПДн граждан РФ — на серверах в РФ (ст. 18 152-ФЗ, локализация БД).
- Политика конфиденциальности и уведомление в Роскомнадзор как оператор ПДн.
- Несовершеннолетние: публикацию в каталоге для них не открывать (или только с согласия законного представителя).

**Механики, зафиксированные в дизайне:**
- Последний шаг конструктора: обязательный чекбокс согласия на обработку ПД (без него не продолжить) + отдельный опциональный чекбокс «Опубликовать в Базе резюме».
- Публичная страница резюме из Базы: контакты скрыты до входа работодателя (не просто «через форму» — работодателю нужен аккаунт). Карточки в каталоге: профессия, раздел, город, опыт, желаемая зарплата, дата обновления — без ФИО и контактов.
- Email-подписка «на новые резюме» по выбранным разделам/специальностям — отдельное согласие на рассылку (ст. 18 закона «О рекламе» + 152-ФЗ), двойное подтверждение (double opt-in), отписка в один клик из письма.

**Влияние на data-model:** у резюме нужны флаги `is_public`, `consent_distribution` (с датой и версией текста согласия), маска публикуемых полей; таблица подписок (email, разделы, статус подтверждения); роль «работодатель» для доступа к контактам. Детали — в `data-model.md`.

Не юридическая консультация — перед запуском каталога согласовать формулировки согласий и политику с юристом.
