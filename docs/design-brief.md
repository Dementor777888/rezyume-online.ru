## 1. Контекст продукта

Сервис создания красивого резюме для русскоязычной аудитории. Пользователь заполняет квиз (в платной версии — диктует голосом), выбирает шаблон, получает PDF/DOCX. **Модель: бесплатно — уровень платных конкурентов (2 цветастых шаблона, PDF, ссылка 24 ч, без регистрации); платно 99 ₽ разово — AI-слой (улучшение фото, все 5 пресетов, DOCX, бессрочная ссылка, личный кабинет, позже голос и «честный разбор»).** Без подписки.

Аудитория: люди в поиске работы, без навыков вёрстки, ценят скорость и результат. Обращение на «Вы».

**Характер бренда:** дружелюбный + лёгкая корпоративность. Минимализм. Всё ведёт к результату прямо, без декоративного мусора. Честность на каждом экране (никаких скрытых списаний).

## 2. Визуальный язык

Фирменный стиль — эко/природный: зелёная листва + жёлтая галочка, логотип с засечками, слоган «Ваш опыт — наши возможности». Это язык **сайта и бесплатных шаблонов**. Платные пресеты — строже и спокойнее (см. разд. 5), чтобы оплата ощущалась апгрейдом.

**Дизайн-токены (бренд/сайт):**

Цвет:
- Зелёный бренд: `#7CB342` (насыщенный), `#8BC34A` (светлее)
- Жёлтый акцент/CTA: `#F5A623` — все кнопки действия, галочки, «Оплатить»
- Светло-зелёная плашка: `#DCEDB9`
- Синий `#4A9FD4` — только в иллюстрациях/аватарах, НЕ в UI-кнопках
- Текст: `#2B2B2B` основной, `#5B6472` вторичный. Линии: `#E4E7EC`
- Фон: `#FFFFFF`, `#F7FAF2` (тёплый светлый)
- Успех `#12A150`, ошибка `#E5484D`, предупреждение `#F5A524`

**Правило акцентов:** жёлтый = действие, зелёный = бренд/навигация/успех.

Спокойные акценты для платных шаблонов резюме: синий `#2E5FE8`, teal `#0E9C8A`, графит `#374151`.

Типографика (полная кириллица обязательна):
- Логотип: serif
- UI: **Golos Text** или **Inter**
- Резюме платные (дефолт): **Inter / Manrope**
- Резюме академический пресет: **PT Serif / Lora**

Сетка и форма:
- Базовый шаг 8px
- Радиусы: карточки 12px, инпуты 8px, кнопки 10px
- Тени мягкие, минимальные
- Характер: дружелюбный природный минимализм, много белого и светло-зелёного воздуха

Элемент бренда: декоративная волна с листвой внизу лендинга.

## 3. Чего НЕ делать (антипаттерны — прямые запреты для дизайна)

- Никаких фейковых таймеров и «-20% только сейчас».
- Никаких предвыбранных галочек подписки. Подписки нет в принципе.
- Никакой OAuth-стены до первого результата. Регистрация — только на шаге сохранения/экспорта.
- Не прятать цену до финала: модель оплаты видна заранее.
- Не заставлять платить за скачивание базового файла.
- Не перегружать шаблоны декором, рамками, лишними иконками.

## 4. Экраны приложения (MVP)

Для каждого экрана нужны: десктоп + мобайл, и состояния (empty / loading / error), где применимо.

**4.1. Лендинг.**
Hero: оффер «Красивое резюме — бесплатно. AI-версия, которая проходит отсев работодателей, — 99 ₽ один раз, без подписки». Крупный CTA «Создать резюме бесплатно». Ниже: «Как это работает» (3 шага с иконками), сравнение Бесплатно/За 99 ₽ честной таблицей, превью галереи шаблонов, блок доверия (оплата один раз · без подписки · открытые реквизиты ИП · бесплатная версия без урезаний), короткий FAQ, футер. 1–2 экрана до CTA. Тон дружелюбный, спокойный.

**4.2. Конструктор резюме — ядро.**
Пошаговый визард с трекером «Шаг X из N». Слева — поля текущего шага с подсказками (soft/hard skills, готовые формулировки), справа — **live-превью резюме, sticky**, обновляется по мере ввода. Шаги: Контакты → Личная информация → Опыт → Образование → Курсы → Навыки → Доп. информация. Секции опыта/образования добавляются и удаляются кнопками «+/−», порядок можно менять. Автосохранение черновика (индикатор «сохранено»).
Мобайл: превью уезжает в нижнюю модалку/кнопку «Посмотреть резюме», форма в одну колонку.
Состояния: пустой шаг, загрузка фото + улучшение (до/после), ошибка валидации поля.

**4.3. Загрузка фото.**
Free: загрузка (drag-n-drop), кроп круг/квадрат, вставка как есть. Paid: то же + AI-улучшение с показом «до → после» и кнопкой «Применить». Улучшение подаётся как платная фича с превью-тизером.

**4.4. Галерея шаблонов.**
Сетка превью. Free-зона: 2 цветастых шаблона (без фото / с фото) — стиль уровня конкурентов, помечены «Бесплатно». Paid-зона: 5 пресетов с настройкой цвета/шрифта, помечены «99 ₽ · разово». Примерка любого на введённых данных (не на плейсхолдере) — и бесплатных, и платных.

**4.5. Превью + экспорт.**
Крупное превью готового резюме. Free: кнопка «Скачать PDF — бесплатно» + ссылка на 24 ч. Paid: переключатели шаблона/цвета/шрифта, форматы PDF+DOCX, кнопка «Открыть всё — 99 ₽, один раз». Сравнение free/paid — честной таблицей рядом, без ущемления бесплатного результата.

**4.6. Экран оплаты.**
Первый шаг — поле email с пояснением: «Создадим личный кабинет и пришлём пароль — резюме сохранится навсегда». Далее заголовок: «Оплата один раз. Без подписки. 99 ₽». Что входит (AI-фото, все шаблоны, PDF+DOCX, бессрочная ссылка, кабинет, правки и скачивания — бесплатно). Поле промокода (свёрнуто в ссылку «У меня есть промокод»). Способы оплаты (YooKassa: карта, SberPay, ЮMoney, T-Pay). Без таймеров, без галочек подписки. Экран успеха: файлы, ссылка, «пароль от кабинета — на почте».

**4.7. Личный кабинет «Мои резюме» (только платные).**
Список резюме карточками: миниатюра, название, статус, бессрочная ссылка, кнопки редактировать/скачать/поделиться. Плашка «правки и скачивания — бесплатно». Empty-state не нужен в обычном флоу (кабинет создаётся вместе с первой оплатой), но предусмотреть на случай удаления резюме.

**4.8. Auth.**
Вход по email + паролю (пароль пришёл на почту при оплате) + восстановление пароля. Появляется только у платящих. Бесплатный флоу регистрации не требует вообще.

**4.9. Публичная страница резюме (по ссылке).**
Чистый просмотр резюме по ссылке. Для платных — бессрочно, для бесплатных — плашка «ссылка активна 24 часа». Контакты по умолчанию видны владельцу; для каталога — скрыты (см. 4.10).

**4.10. Позже (Шаг 2–3), заложить визуально, но не в MVP:**
Голосовая надиктовка (экран записи + разбор по полям), экран «честного разбора» (вердикт, сильные стороны зелёным, риски красным, ATS-% с причинами, «Было → Стало», вопросы на собеседовании с «почему спросят»), SEO-каталог (страница профессии, пример резюме), каталог резюме пользователей (opt-in, контакты скрыты, отклик через форму — по 152-ФЗ, см. `PRD.md` разд. 9).

## 5. Шаблоны резюме (визуальные референсы)

Нужно 7 шаблонов: 2 бесплатных + 5 платных пресетов. Полная кириллица везде.

### Бесплатные (уровень платных шаблонов конкурентов, цветастые)

**5.0a. «Старт» (без фото).** Две колонки, яркая цветная шапка/сайдбар в духе массовых конкурентов (референсы — наши DOCX 1–15). Выглядит достойно — это наша витрина щедрости, не обрубок. Используется автоматически, если фото не загружено.

**5.0b. «Старт+фото».** Тот же характер, с местом под фото (пользователь вставляет своё, без AI-улучшения). Используется автоматически при наличии фото.

### Платные пресеты (минимализм + лёгкая корпоративность)

Общий принцип: один спокойный акцент, крупный хедер «Имя + должность + тонкая линия», аккуратные иконки контактов и дозированные шкалы навыков. Фото — опционально, с AI-улучшением.

**5.1. «Чистый» (дефолт).** Две колонки, левый сайдбар (контакты, навыки, языки) со светлой заливкой; правая — опыт, образование, курсы. Sans (Inter/Manrope). Фото круглое вверху сайдбара. Акцент — в заголовках секций и линиях. Плотность воздушная. Это главный референс.

**5.2. «Компакт».** Две колонки, плотнее, для большого опыта. Акцентные линии-разделители, фото квадратное. Sans. Меньше воздуха, больше содержания на страницу.

**5.3. «Одна колонка» (ATS-friendly).** Один столбец, без сайдбара, крупный хедер + линия, простые секции. Sans, минимум декора. Задел под будущую ATS-проверку. Фото опционально сверху.

**5.4. «Академический».** Один столбец, serif (PT Serif/Lora), монохром без акцента, линии-разделители секций, без фото. Строгий/госсектор. Опциональный пресет, не дефолт.

**5.5. «Акцент».** Две колонки с заливкой сайдбара акцентным цветом (сдержанно), белый текст в сайдбаре. Более смелый, но всё ещё чистый. Для тех, кто хочет ярче.

Для каждого шаблона: превью на реалистичных данных (русские ФИО, должность, опыт), десктоп-миниатюра для галереи и полноразмерный вид. Показать варианты акцентного цвета (синий/teal/графит).

   образования с кнопками +/−. Индикатор автосохранения. Мобайл: превью в нижней модалке.
3. Загрузка фото — free: вставка как есть (кроп круг/квадрат). Paid: + AI-улучшение
   «до → после» с кнопкой «Применить», подано как платная фича с превью-тизером.
4. Галерея шаблонов — free-зона (2 фирменных шаблона, бейдж «Бесплатно») и paid-зона
   (5 пресетов + настройка цвета/шрифта, бейдж «99 ₽ · разово»). Примерка любого на своих
   данных.
5. Превью + экспорт — крупное превью. Free: «Скачать PDF — бесплатно» + ссылка 24 ч.
   Paid: переключатели шаблон/цвет/шрифт, PDF+DOCX, кнопка «Открыть всё — 99 ₽, один раз».
   Честное сравнение free/paid рядом.
6. Оплата — шаг 1: поле email («создадим кабинет и пришлём пароль — резюме сохранится
   навсегда»). Шаг 2: «Оплата один раз. Без подписки. 99 ₽», что входит, поле промокода
   (свёрнуто в ссылку), способы оплаты (YooKassa: карта, SberPay, ЮMoney, T-Pay).
   Экран успеха: файлы + «пароль от кабинета на почте».
7. Личный кабинет «Мои резюме» (только платные) — карточки: миниатюра, название, статус,
   бессрочная ссылка, редактировать/скачать/поделиться. Плашка «правки и скачивания
   бесплатны».
8. Auth — вход email + пароль (пришёл при оплате) + восстановление. Только для платящих.
9. Публичная страница резюме по ссылке — чистый просмотр; для бесплатных плашка
   «ссылка активна 24 часа».
